Adrenal Steroid Synthesis Pathway

Click any node to reveal the zone, enzyme, and clinical significance. Master this to decode any CAH variant.

Cholesterol → Adrenal Steroids
ACTH drives cortisol + androgens. Angiotensin II drives aldosterone. Zone determines enzyme expression.
All zones — rate-limiting

Cholesterol → Pregnenolone

StAR protein transports cholesterol into inner mitochondrial membrane (rate-limiting). CYP11A1 (side-chain cleavage) then cleaves cholesterol → pregnenolone. ACTH, LH, FSH all stimulate StAR. Lipoid CAH = StAR deficiency → no steroid synthesis at all.
All zones

Pregnenolone → Progesterone

3β-HSD (3β-hydroxysteroid dehydrogenase): converts Δ5 → Δ4 steroids. Required for cortisol, aldosterone, AND androgens. Deficiency → all three pathways impaired → salt-wasting + ambiguous genitalia in both sexes.
Zona Fasciculata only

Progesterone → 17-OHP

CYP17A1 (17α-hydroxylase): adds hydroxyl at C17. Required for cortisol AND sex steroids. NOT in zona glomerulosa → why aldosterone synthesis doesn't require 17α-hydroxylation. 17α-OHD = no sex steroids + no cortisol + DOC ↑ → HTN.
Zona Fasciculata + Glomerulosa

17-OHP → 11-Deoxycortisol
Progesterone → DOC

CYP21A2 (21-hydroxylase): most common CAH deficiency (90-95%). Blocks BOTH cortisol AND aldosterone synthesis. 17-OHP accumulates → shunts to androgen pathway. Classic: salt-wasting + virilization. 17-OHP is the diagnostic marker.
Zona Fasciculata

11-Deoxycortisol → Cortisol

CYP11B1 (11β-hydroxylase): 2nd most common CAH (5-8%). DOC and 11-deoxycortisol accumulate. DOC = potent mineralocorticoid → HTN + hypokalemia (opposite of 21-OHD). Virilization still occurs from androgen excess. KEY: HTN distinguishes from 21-OHD.
Zona Glomerulosa only

DOC → Corticosterone → Aldosterone

CYP11B2 (aldosterone synthase): only in zona glomerulosa. Stimulated by Ang II + K⁺ (NOT primarily ACTH). Deficiency → salt-wasting WITHOUT virilization (no androgen excess because ACTH/adrogens aren't affected).
Zona Reticularis

17-OHP → DHEA → Androstenedione

CYP17A1 lyase activity + 3β-HSD: produces adrenal androgens. DHEA-S is the main adrenal androgen. In CAH: ACTH ↑↑ drives this zone → androgen excess → virilization in females, precocious pseudo-puberty in males. Peripheral conversion: DHEA → androstenedione → testosterone.
Adrenal Medulla

Tyrosine → DOPA → DA → NE → Epi

Tyrosine hydroxylase (rate-limiting) → DOPA decarboxylase → Dopamine β-hydroxylase → PNMT (NE→Epi). PNMT requires high glucocorticoid from cortical portal blood. Paragangliomas lack PNMT → secrete NE only. Pheo: unregulated catecholamine secretion.
CAH Comparison Node

Key Substrate Accumulations by CAH Type

21-OHD: 17-OHP ↑↑↑ → salt-wasting + virilization.
11β-OHD: 11-deoxycortisol + DOC ↑ → HTN + virilization (no salt-wasting).
17α-OHD: no 17-OHP (never made) → no sex steroids + DOC ↑ → HTN.
3β-HSD: DHEA-S ↑↑ → affects all three pathways.
